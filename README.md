## Оповещения врача и VK-бот

Telegram в проекте не используется. Все уведомления идут через сообщения
сообщества ВКонтакте: пациенту — подтверждение, напоминание, отмена; врачу —
новая запись, отмена, просьба связаться, входящие сообщения и утренняя сводка.

Настройка на сервере (`.env`):

- `VK_DOCTOR_USER_IDS` — числовые id личных страниц VK врача/администратора
  через запятую. Каждый из них должен **один раз написать сообществу**,
  иначе VK не даст сообществу писать им.
- `DOCTOR_ALERT_EMAILS` и `EMAIL_*` — резервный email, если VK-алерт не дошёл.
- `TIME_ZONE` — пояс, в котором вводятся слоты (`Asia/Tomsk` по умолчанию,
  `Europe/Moscow`, если слоты вводятся по Москве).
- `VK_GROUP_DOMAIN` — короткое имя сообщества для ссылки `vk.me/<имя>`.

Проверка канала алертов:

```bash
docker compose -f docker-compose.prod.yml exec backend python manage.py send_test_doctor_alert
```

В настройках сообщества VK → «Управление» → «Работа с API» → «Callback API» →
«Типы событий» должны быть включены: «Входящее сообщение», «Исходящее
сообщение», «Действие с сообщением» (callback-кнопки) и «Разрешение на
получение» сообщений.

Как ведёт себя бот:

- на первое осмысленное сообщение отвечает приветствием с кнопкой записи
  (не чаще раза в 30 дней) и сразу возвращает диалог в «Неотвеченные»;
- о каждом сообщении человека присылает врачу алерт со ссылкой на диалог
  (не чаще раза в 30 минут на собеседника);
- если врач ответил в диалоге вручную, бот молчит в нём 24 часа;
- если пациент записался, но ещё не разрешил сообщения, подтверждение
  придёт, как только он напишет сообществу или разрешит сообщения.
- в приветствии есть кнопки быстрых ответов: это вопросы FAQ, у которых в
  админке заполнено поле «Кнопка в VK-боте» (до 40 символов);
- кнопка «Перенести» в управлении записью и в напоминании показывает
  ближайшие свободные слоты; после переноса врачу приходит алерт. Если врач
  сам меняет слот в админке, пациенту приходит сообщение о новом времени;
- вне рабочих часов (`VK_BOT_WORKING_HOURS`, по умолчанию `09:00-21:00`
  по поясу расписания) бот один раз за ночь отвечает, что врач ответит утром.

## Контент в админке

- «Отзывы» показываются на главной, «Дипломы и сертификаты» на странице
  «О враче». Пока записей нет, блоки на сайте скрыты. Публикуйте только
  настоящие отзывы, которые разрешено использовать.
- Для обложек статей, плиток блога и аватара врача сайт сам делает
  уменьшенные WebP-копии. При старте контейнера их досоздаёт команда
  `python manage.py generate_image_variants`.

## Яндекс Метрика

Счётчик 104693717 подключён в `frontend/app/layout.tsx` (номер можно
переопределить через `NEXT_PUBLIC_YANDEX_METRIKA_ID` при сборке). Переходы
между страницами без перезагрузки отправляются вручную через `hit`, как
требует Метрика для SPA.

Цели воронки записи заводятся в Метрике как «JavaScript-событие» с
идентификаторами:

| Идентификатор | Когда срабатывает |
|---|---|
| `booking_slot_selected` | выбран слот |
| `booking_vk_login` | вход через VK ID |
| `booking_vk_messages_allowed` | разрешены сообщения от сообщества |
| `booking_contact_phone` | выбран вариант «позвоните мне» |
| `booking_open_vk_dialog` | переход в диалог с сообществом |
| `booking_submit` | нажата кнопка записи |
| `booking_success` | запись создана |
| `booking_error` | запись не прошла |
